# 🌿 생태탐구반 동아리 탐구 보고서

봉일천고등학교 **생태탐구반** 동아리의 탐구 과제를 온라인으로 쓰고 제출하는 사이트입니다.
1학년 '진로 빌드업 맵' 탐구 보고서([/report/](https://2023swhs3rd-a11y.github.io/report/))와 구조는 같지만, **동아리 과제 3단계**와 **계열별 생태 주제**로 따로 운영합니다.

- 학생용: https://2023swhs3rd-a11y.github.io/eco-report/
- 선생님용: https://2023swhs3rd-a11y.github.io/eco-report/#teacher
- 대상: 생태탐구반 1~2학년 (학년이 섞여 있어 주제마다 🌱 기본 · 🌳 심화 질문을 둠)

## 과제 구성

| 단계 | 이름 | 하는 일 | 선생님 확인 |
|---|---|---|---|
| 🌱 과제 1 | 주제 정하기 | 계열 고르기 → 주제 카드에서 기본·심화 질문 고르기 → 이유, 이전 활동 연결, 방법, 계획, 안전·윤리 | 확인 ① |
| 🔍 과제 2 | 탐구·기록 | 자료 카드 1장, 날짜별 기록 2번 이상, 결과 모아 보기, 중간 점검(바꾼 점) | 확인 ② |
| 🌳 과제 3 | 보고서·성찰 | 문장 틀 ①~⑦(질문·방법·결과·해석·예상 비교·결론·한계), 나누기, 돌아보기, 진로 연결 | 확인 ③ |

단계마다 '🌱 이것만 하면 완성'(필수 칸)과 '🚀 더 해 보고 싶다면'(도전)을 나눠 보여 줍니다.

## 주제 17가지 (js/schema.js 의 `TOPICS`)

| 계열 | 주제 |
|---|---|
| 🏛️ 인문·사회·상경 | 넛지로 바꾸는 분리배출 · 기후위기와 파주 농업(장단콩·파주쌀) · 생태계 교란 생물과 지자체 정책·조례 · 그린워싱 언론보도와 미디어 캠페인 · 가까운 하천(공릉천) 인식 조사* · 다회용기·제로웨이스트의 경제학* |
| 🔬 자연·생명·공학 | 생물지표종(동백나무·제비나비) 서식지 북상 지도 · 미세플라스틱·산성비와 강낭콩 발아·생장 실험 · 빗물 재활용·태양광 에코 학교 설계 · 네이처링으로 텃새 관찰·도감 · 교실 이산화탄소와 환기* · 나무껍질 지의류로 보는 공기* |
| 🎨 사범·교육·예술 | 초등학생 대상 멸종위기종 생태 감수성 교육 기획 · 기후위기 인포그래픽·포스터 · 자연의 소리와 스트레스 완화 · 생태 그림책 읽고 만들기* · 학교 나무 이름표·QR 생태 안내판* |

\* 표시는 학생 수준을 고려해 더한 주제입니다. 주제마다 🌱 기본 질문, 🌳 심화 질문, 자료·도구, 조심할 점이 있습니다. 학생이 카드에서 고르면 주제·질문·수준·방법 칸이 채워지고, 직접 고쳐 쓸 수 있습니다. 주제를 더하거나 고치려면 `TOPICS` 배열만 고치면 됩니다.

## 처음 설정 (새 구글 시트 1개)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다(예: '생태탐구반 탐구 보고서'). 1학년 보고서 시트와 따로 둡니다.
2. 시트 → 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
3. 왼쪽 ⚙️ 프로젝트 설정 → 스크립트 속성 → `TEACHER_PASSWORD` 에 10자 이상의 교사 비밀번호를 넣습니다.
4. 함수 목록에서 `setup` 을 골라 실행하고 권한을 허용합니다('보고서', '명단' 시트가 생깁니다).
5. 배포 → 새 배포 → 유형: 웹 앱 → 실행: 나, 액세스: 모든 사용자 → 배포 → 웹 앱 주소를 복사합니다.
6. 이 저장소의 `js/config.js` 의 `API_URL` 에 주소를 넣습니다. 비워 두면 미리보기 모드(이 기기에만 저장, 교사 비밀번호 `demo`)로 동작합니다.
7. '명단' 시트에 동아리 학생의 학번·이름을 넣어 두면 명단에 있는 학생만 들어올 수 있습니다(권장).

코드를 바꾼 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 누릅니다. 새 배포를 만들면 주소가 바뀝니다.

## 보안·개인정보

- 교사 비밀번호는 코드가 아니라 Apps Script 스크립트 속성에만 둡니다.
- 학생 비밀번호는 암호화(SHA-256)해 저장하고, 10번 틀리면 15분 잠깁니다. 교사 비밀번호는 10분에 8번 틀리면 10분 막힙니다.
- 기준표·관찰 메모·특기사항 초안은 학생에게 보내지 않습니다.
- 학생 안내: 사람 얼굴 사진, 설문 응답자의 이름·학번 같은 개인정보는 올리지 않습니다. 생물은 잡거나 꺾지 않고 기록만 합니다.
- 동아리활동 특기사항은 2026학년도 기준 500자이며, 예시는 이 탐구에 해당하는 부분만 씁니다. 실제 기록은 선생님이 관찰한 사실로 씁니다.
